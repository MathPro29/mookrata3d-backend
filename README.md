# Mookrata 3D Backend

Supabase PostgreSQL schema used by the Mookrata 3D frontend.

## Setup

1. Create a Supabase project.
2. Run `schema.sql` in the Supabase SQL Editor.
3. Configure `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` in the frontend environment.

The frontend also supports standalone demo mode without Supabase.
